# ALO — রিয়েল-টাইম ভিডিও/ভয়েস কল ও চ্যাট অ্যাপ

Node.js (কোনো npm প্যাকেজ লাগে না) + WebRTC। ফ্রন্টএন্ড আপনার দেওয়া ALO ডিজাইনের উপর তৈরি।

## চালানোর নিয়ম
```bash
cd alo
node server.js          # http://localhost:3000
node test.js            # সার্ভারের ৩০টি অটো-টেস্ট
```
দুটি ব্রাউজার/ট্যাব (বা দুটি ডিভাইস) খুলে আলাদা নম্বর দিয়ে অ্যাকাউন্ট খুলুন → একজন অন্যজনকে
"Add" বাটনে ফোন নম্বর (কান্ট্রি কোডসহ) বা `@alo_id` দিয়ে খুঁজে যোগ করুন → চ্যাট ও কল করুন।

> **গুরুত্বপূর্ণ:** ক্যামেরা/মাইক ব্রাউজারে শুধু `https://` বা `localhost`-এ চলে।
> অন্য ফোন/কম্পিউটার থেকে টেস্ট করতে HTTPS লাগবে (নিচে দেখুন)।

## যা যা কাজ করে
- অ্যাকাউন্ট (ফোন + পাসওয়ার্ড, scrypt হ্যাশ), লগইন সেশন, প্রোফাইল ছবি/বায়ো/ALO আইডি
- কন্টাক্ট খোঁজা ও যোগ করা, অনলাইন/লাস্ট-সিন
- রিয়েল-টাইম চ্যাট: sent ✓ / delivered ✓✓ / read (নীল ✓✓), টাইপিং ইন্ডিকেটর, আনরিড কাউন্ট, ব্রাউজার নোটিফিকেশন
- ভয়েস ও ভিডিও কল (WebRTC), রিংটোন/রিংব্যাক, ইনকামিং কল স্ক্রিন, busy / offline / reject / 60s টাইমআউট
- কল চলাকালীন: মিউট, ভিডিও অন/অফ (ভয়েস কলকে ভিডিওতে আপগ্রেডসহ), ক্যামেরা ফ্লিপ, স্পিকার, স্ক্রিন শেয়ার,
  ফিল্টার (অপর পক্ষও দেখে), রিঅ্যাকশন, কল-চ্যাট, কল টাইমার
- কল রেকর্ডিং (দুই পক্ষের অডিও + ভিডিও মিক্স) → ব্রাউজারের IndexedDB-তে সেভ, প্লে/ডাউনলোড/ডিলিট।
  রেকর্ড শুরু করলে অপর পক্ষ "রেকর্ড করছে" নোটিস দেখে।
- কল হিস্ট্রি (incoming / outgoing / missed, সময়কাল), বাংলা ও English UI

## ডিপ্লয় (প্রোডাকশন)
1. **HTTPS**: হয় রিভার্স প্রক্সি (Caddy/nginx) ব্যবহার করুন, নয়তো সরাসরি:
   `SSL_KEY=key.pem SSL_CERT=cert.pem PORT=443 node server.js`.
   nginx-এ SSE-র জন্য `proxy_buffering off;` দিন।
2. **TURN সার্ভার** (আলাদা নেটওয়ার্ক/মোবাইল ডাটায় কল কানেক্ট হতে প্রায় জরুরি — শুধু STUN দিয়ে ~১০–২০% কল ফেইল করে):
   coturn চালিয়ে
   `TURN_URL=turn:your.host:3478,turns:your.host:5349 TURN_SECRET=<static-auth-secret> node server.js`
   (অথবা fixed ইউজার/পাস: `TURN_USER` + `TURN_PASS`)।
3. ডেটা `data/db.json`-এ থাকে (`DATA_DIR` দিয়ে বদলানো যায়)। ব্যাকআপ রাখুন।

## সীমাবদ্ধতা (সৎ কথা)
- শুধু ১-টু-১ কল (P2P)। গ্রুপ কল চাইলে LiveKit/Agora/mediasoup লাগবে।
- অ্যাপ/ট্যাব বন্ধ থাকলে ইনকামিং কল/মেসেজের পুশ নোটিফিকেশন নেই (Web Push/FCM যোগ করতে হবে)।
  অফলাইনে থাকা ব্যবহারকারীকে কল করলে "অফলাইন" দেখায় ও তার কল হিস্ট্রিতে মিসড কল থাকে।
- জেসন ফাইল ডেটাবেস — হাজার-দশেক ব্যবহারকারী পর্যন্ত ঠিক আছে; এরপর PostgreSQL-এ নিন।
- ফিল্টার Safari-তে কাজ নাও করতে পারে; স্ক্রিন শেয়ার মোবাইল ব্রাউজারে নেই।
- UI Tailwind CDN (`cdn.tailwindcss.com`) ও Google Fonts ব্যবহার করে — ইন্টারনেট লাগে।
- কল রেকর্ডিং আইনত সম্মতি-সাপেক্ষ; নিজ দেশের আইন মেনে ব্যবহার করুন।

- `test.js` — ইন্টিগ্রেশন টেস্ট
